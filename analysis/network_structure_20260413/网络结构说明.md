## 总览

```text
Actor:  共享 actor，3 架追捕无人机共用同一套参数
        CoopEntityAttentionEncoder, 2 层 TransformerEncoderLayer
        输出 4 维 PIDrate action 分布均值 + learned log_std

Critic: centralized critic
        RelationEncoder
        输出 state_value

TP:     目标预测网络
        1 层 LSTM, hidden_dim=64
        输出未来 5 步目标 xyz
```

## Actor

```text
Per-agent observation TensorDict
  state_self + cooperation + state_others + optional cylinders
        |
        v
Entity embeddings
  self_embed: Linear -> 128
  other_embed: Linear -> 128
  cylinder_embed: Linear -> 128
        |
        v
Token concat + mask + LayerNorm(128)
        |
        v
TransformerEncoder x 2
  embed_dim = 128
  num_heads = 4
  dim_feedforward = 256
  activation = GELU
  dropout = 0
        |
        v
Encoded self token, feature_dim = 128
        |
        v
TanhIndependentNormal action head
  fc_mean: Linear 128 -> 4
  learned log_std: shape [4]
        |
        v
PIDrate action [4]
  omega_x, omega_y, omega_z, thrust
```

注意：

- `share_actor: true`，所以三架追捕无人机共享同一个 actor。
- actor 的 `hidden_units: [256, 256, 256]` 在当前 Composite observation + `CoopEntityAttentionEncoder` 路径里不是主体 MLP 层数；真正主体是 2 层 Transformer encoder。
- `bc_aux.enabled=false`，所以当前 RL 训练没有启用额外 BC 辅助预测头。
- RNN 是注释状态，没有启用 GRU。

## Critic

```text
Centralized agents/state
        |
        v
RelationEncoder
  SplitEmbedding, embed_dim = 72
        |
        v
Pairwise relation ij(a)
        |
        v
g network
  MLP: 144 -> 256
  LayerNorm(256)
        |
        v
Sum over pairs
        |
        v
f network
  MLP: 256 -> 128
        |
        v
Value head
  Linear 128 -> state_value
```

注意：

- critic 使用 `critic_input: state`，是 centralized critic。
- critic 不是 3 层普通 MLP，而是 RelationEncoder + value head。
- `value_norm` 使用 `ValueNorm1(beta=0.995)`。

## 训练耦合关系

```text
Actor action -> Isaac/PIDrate environment -> reward/returns -> PPO
Critic value -> value_loss -> PPO
TP prediction -> actor observation/state and role_reward waypoint
Expert2 policy -> expert_action -> fixed_std_nll Expert KL -> actor loss
```

当前 actor loss 近似为：

```text
L_actor ≈ L_PPO + alpha * L_expert
L_expert = 0.5 * mean((actor_action_mean - expert_action)^2) / 0.15^2
```

其中 `alpha` 从 `0.4` 衰减到 `0.05`。
