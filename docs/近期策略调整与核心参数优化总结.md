# 多无人机追逃：近期策略调整与核心参数优化总结

本文档是对近期在多无人机追逃（Multi-UAV Pursuit-Evasion）任务中进行的一系列策略架构升级和核心参数优化的详细总结。在此次迭代中，我们从底层的动作参数化重构、再到分层控制架构演进，最后通过专家策略底层参数的精细调校，大幅提升了系统的捕获率并降低了坠机率。

## 一、 RL 动作参数化重构与热启动（Warm-start）修复

### 1.1 核心问题
在尝试使用预训练的专家策略对 PPO 模型进行热启动（Warm-started fine-tuning）时，遭遇了严重的性能退化（Performance degradation）。经过深入排查，发现根本原因在于动作边界处理存在**重复的 Tanh 压缩算法（Double-tanh squashing）**，导致动作空间严重失真，模型真实探索能力受限。

### 1.2 解决方案
- **重构动作空间分布**：将模型动作参数化方法正式迁移到了 `TanhIndependentNormal`。
- **匹配控制逻辑**：使 Actor 的输出空间分布直接与环境控制逻辑底层严格对齐。
- **探索噪声控制**：对网络输出的 `log_std` 进行了合理的剪切（clamping）控制。

### 1.3 收益分析
这一改动完美消除了重复 Tanh 压缩效应，不仅使得专家行为在 PPO 微调初期得到了高保真度的继承和保留，也极大地稳定了训练前期的收敛过程。

## 二、 架构演进：分层控制与网络结构优化

### 2.1 核心问题
在真实场景下，简单的质点模型（Point-mass model）表现与真实高逼真度的六自由度（6-DOF）物理模型之间存在显著的性能鸿沟（Performance gap）。原先的单层 RL 网络不仅经常输出物理不可行的期望速度指令，而且导致了高延迟追踪和剧烈的飞控震荡。

### 2.2 解决方案
- **分层解耦控制（Hierarchical Control Framework）**：我们将高维度的“战术/战略决策层”与底层的“姿态/飞行控制层”进行了物理分离。在两者之间引入运动规划层，确保高层给出的期望速度（Velocity commands）绝对处于底层 6-DOF 无人机的物理可执行范围内。
- **Actor-Critic 辅助任务网络（Auxiliary Task Branches）**：在网络侧引入了额外的辅助任务预测分支，以指导模型学习更为丰富和鲁棒的状态特征。

### 2.3 收益分析
加入辅助分支后，网络特征提取的表征能力大幅上升，策略输出更加平滑；解耦控制后彻底降低了由指令不可行引发的稳定性崩坏风险，为后续减少碰撞、提升鲁棒性奠定了坚实基础。

## 三、 专家策略关键参数调优（性能大幅提升的核心）

在修正了系统架构之后，我们对启发式（Heuristic）专家策略进行了最后的精细微调，致力于在“激进的高效追踪”与“保守的飞行安全”中取得最佳平衡。

### 3.1 参数调整详情
我们主要更新了以下三个影响追踪姿态与激进程度的核心控制参数：
1. **角度阈值（$\theta$）设定为 25°**：优化了相对截获角的要求，放宽绝对对齐要求，避免因针对小角度死磕带来的自旋和失速。
2. **比例增益积分（$P$）设定为 2.0**：调节前向跟随的推力增益，防止过大的加速度带来过冲（Overshoot）。
3. **偏航角速度缩放系数调整为 $\omega \times 0.65$**：削弱了转向时的最大角速度极限限制。

### 3.2 量化结果（Metrics Improvement）
调整参数后，系统整体评价指标得到了质的飞跃（部分代价为任务超时率有非常微小的上升，但综合收益巨大）：
- **坠机率（Crash Rate）显著下降**：从原本的 **17%** 骤降至 **8%**。
- **捕获率（Capture Rate）显著提升**：从原本的 **68%** 增长至 **74%**。

### 3.3 原理剖析
旧参数的设定过于激进，导致无人机极易在极端拐角或高速追击中出现过度控制（Over-control），从而直接造成不可逆转的坠机（包含与其他无人机相撞或坠地）现象。

全新的参数组合（$\theta=25^\circ, P=2.0, \omega \times 0.65$）成功**降低了偏航过敏与系统剧烈震荡**。策略通过稍显保守但极度稳定的飞控姿态，换取了机群整体的存活率。事实证明，利用稳定、持续且安全的包围策略，能带来比极限竞速更高的最终捕获率。
